Current Projects

Quantitative finance and data science projects. Source code on GitHub.

Options Pricing Engine

Options pricing library implementing Black-Scholes, Binomial Trees, and Monte Carlo simulation for European and American options. Includes Greeks (Delta, Gamma, Vega, Theta, Rho) computation and an implied volatility solver via Brent's method.

Python Derivatives Monte Carlo Black-Scholes Greeks

Portfolio Optimizer

Mean-variance portfolio optimization with Markowitz efficient frontier, Black-Litterman model, and risk parity allocation. Backtesting framework with transaction cost modeling, drawdown analysis, and Sharpe/Sortino ratio reporting.

Python Portfolio Theory Optimization Backtesting Risk

Stochastic Volatility Models

Calibration and simulation of Heston, SABR, and rough Bergomi stochastic volatility models. Finite difference PDE solver for option pricing under local vol surface, with volatility surface visualization tools.

Python C++ Stochastic Vol Heston PDE Calibration

Equity Factor Model Research

Multi-factor equity model inspired by Fama-French. Implements momentum, quality, value, and low-volatility factors with PCA-based factor extraction, Ledoit-Wolf covariance shrinkage, and walk-forward cross-validation.

Python R Factor Models PCA Equity Alpha Research

ML-Based Regime Detection

Hidden Markov Model and change-point detection for identifying bull/bear market regimes. Ensemble of Gaussian HMM, CUSUM, and LSTM-based classifier, evaluated on S&P 500 and VIX time series.

Python Machine Learning HMM LSTM Time Series

Spatial Transcriptomics Workflow

Graduate thesis research pipeline identifying immune-function signatures in vaping-associated pulmonary injury using spatial gene expression data. Bayesian inference, clustering, and tissue-level expression visualization.

R Python Bioinformatics Bayesian Clustering Research

Planned / In Progress

Projects currently in research or early development.

Reinforcement Learning for Portfolio Management

Deep RL agent (PPO/SAC) trained to manage a multi-asset portfolio under realistic market microstructure constraints — including transaction costs, slippage, and position limits. Benchmarked against equal-weight and momentum baselines.

Python Reinforcement Learning Portfolio PPO In Progress

CUDA Monte Carlo Simulator

GPU-accelerated Monte Carlo engine for pricing exotic derivatives and running large-scale scenario analysis. Uses CUDA parallel random number generation (cuRAND) with variance reduction techniques: antithetic variates, control variates, quasi-Monte Carlo.

C++ CUDA GPU Monte Carlo Exotic Options Planned

Yield Curve Modeling & Fixed Income Analytics

Nelson-Siegel-Svensson yield curve fitting, bootstrapping from market instruments, and duration/convexity analytics. Includes short-rate model simulation (Vasicek, Hull-White) for interest rate derivatives pricing.

Python Fixed Income Yield Curve Interest Rates Planned

Statistical Arbitrage Backtester

Event-driven backtesting framework for pairs trading and cointegration-based stat-arb strategies. Engle-Granger and Johansen cointegration tests, Kalman filter for dynamic hedge ratio estimation, and realistic execution modeling.

Python Stat Arb Cointegration Kalman Filter Planned
