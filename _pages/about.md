I build data systems that automate complex workflows. Currently at [Westcliff University](https://www.westcliff.edu/), I design and deploy cloud infrastructure for document processing pipelines and agentic AI systems—transforming manual processes into scalable, automated solutions.

My background combines quantitative rigor with systems engineering. I completed a Master's in Applied Mathematics (thesis: spatial transcriptomics for immunological analysis), which shaped how I approach data pipelines: with statistical precision, careful validation, and respect for domain complexity. On the engineering side, I've built production ETL systems, distributed computing solutions, and orchestration layers that integrate APIs, cloud storage, and computational workflows.

What I'm strongest at: **taking a tangled integration problem and building a clean, maintainable system for it**. Whether it's coordinating Zoom API ingestion → S3 → analysis pipelines, or automating document workflows across multiple services, I focus on understanding the real problem first, then engineering the right solution.
